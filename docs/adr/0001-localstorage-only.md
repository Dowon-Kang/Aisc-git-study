# 0001 · 서버 없이 localStorage에만 저장

- 상태: 채택 · 날짜: 2026-11-22 · 관련: PRD 4. 범위

## 배경
실습 목표는 Git·GitHub 협업 흐름을 끝까지 경험하는 것입니다. 서버·DB까지 만들면 하루 안에 “전체 실행 확인”까지 가기 어렵습니다.

## 결정
데이터는 브라우저 localStorage(`aisc-study-hub-v1` 키)에만 저장합니다. 읽기·쓰기는 `src/domain/storage.ts`만 합니다.

## 대안
- Firebase·Supabase: 여러 기기 공유는 되지만 계정·키 관리가 실습 범위를 넘음
- Express + JSON 파일 서버: 프론트·백 분리 경험은 되지만 실행 단계가 둘로 늘어남

## 영향
- 같은 브라우저에서만 데이터가 보입니다. 팀원끼리 데이터를 공유하지 않습니다.
- 나중에 서버로 바꾸면 `storage.ts`만 교체하도록 기능 코드는 저장을 직접 다루지 않습니다.
