## 해결할 문제 (P1)
바쁜 시간을 칸마다 직접 칠하는 것도 번거롭다. 이미 에브리타임에 있는 시간표를 다시 입력하고 싶지 않다.

## 작업 설명
각자 에브리타임 시간표 캡처를 올리면 서버가 이미지를 인식해 바쁜 시간 후보를 만들고, FREE-1 그리드에 미리 칠해 줍니다. 사용자가 확인·수정한 뒤 저장합니다. (ROADMAP 6절, FREE-1 이후)

## 할 일
- [ ] ADR(상태: 제안): 인식에 쓸 AI 서비스·모델, 월 비용 상한, 이미지 보관 정책
- [ ] 서버 엔드포인트: 이미지 업로드 → 인식 → `BusyBlock` 후보 JSON (요일·시작·끝·확신도)
- [ ] 응답 검증: 요일 범위, 30분 단위, 시작 < 끝, 스키마 불일치 시 실패 처리
- [ ] 확신도가 낮은 칸은 그리드에서 다른 색으로 표시, 저장 전 확인 단계 필수
- [ ] 정확도 측정: 동의받은 샘플 캡처 5장 이상 + 정답 JSON, 칸 단위 일치율 스크립트
- [ ] 과목명·교수명·강의실은 저장하지 않음, 원본 이미지는 인식 후 삭제

## 수용 조건
- [ ] 샘플 캡처에서 칸 단위 일치율 90% 이상(측정 결과를 PR에 첨부)
- [ ] 인식 결과를 그리드에서 고친 뒤 저장할 수 있고, 저장된 값으로 공강이 계산된다
- [ ] 인식 실패·스키마 불일치·느린 응답 때 “직접 칠해 주세요” 안내와 함께 FREE-1 그리드로 돌아간다
- [ ] 저장소와 브라우저 코드에 AI 키가 없다

## 하지 않는 것
에브리타임 로그인·링크 크롤링, 과목 정보 저장, 여러 학기 관리
