## 작업 설명
지금까지의 일정 제목·주제를 바탕으로 스터디 흐름 요약과 다음 주제 후보 3개를 보여 줍니다. (ROADMAP AI)

## 할 일
- [ ] AI 서비스·모델 선택과 월 비용 상한 ADR(상태: 제안)
- [ ] 키를 서버에서만 쓰는 구조(브라우저에 키를 넣지 않음)
- [ ] 보내는 데이터 목록 — 멤버 이름은 보내지 않음
- [ ] 실패·느린 응답일 때 화면 문구

## 수용 조건
- [ ] 버튼을 누르면 요약 한 문단과 주제 후보 3개가 보인다
- [ ] 요청에 멤버 이름이 들어가지 않는다(로그로 확인)
- [ ] AI 응답이 실패해도 나머지 화면은 그대로 동작한다
